# WellScope

Grounded Q&A assistant for daily drilling (DDR) and geological (DGOS) well reports:
layout-aware PDF parsing, hybrid retrieval and cited answers.

> Work in progress. The specification lives in [`docs/specs/`](docs/specs/) and the engineering
> standards in [`docs/STANDARDS.md`](docs/STANDARDS.md). Full installation and usage
> documentation ships with v1.0.0.
